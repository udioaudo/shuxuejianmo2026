# 运行说明

## 环境

开发环境为 Windows 11、Python 3.13.5，需要 Python 3.11 或更新版本。在本目录下安装依赖：

```
python -m pip install -r requirements.txt
```

论文用图的中文字体为 Microsoft YaHei，Windows 自带；在其他系统上运行时图中汉字可能显示为方框，不影响数值结果。

## 运行

- 只检查、不需要原始附件：`python run.py --check`，核对随附结果文件是否齐全，并运行 28 项单元测试（全部为构造数据）。
- 完整复现：先按 `02_data/raw/数据放置说明.md` 放入原始附件，再运行 `python run.py`（Windows 可双击 `run.bat`，Linux 与 macOS 用 `bash run.sh`）。
  程序依次运行 `03_src/run_all.py` 的 34 个步骤、附件登记审计（`03_src/run.py audit`）和 4 个论文补充程序（指标相关、附件概况、补充数据图、流程图），最后运行单元测试。
  单线程约 4 分钟，结果写入 `05_results/`，日志写入 `08_logs/full_pipeline.log`。

## 目录

| 位置 | 内容 |
|---|---|
| `03_src/q1` 至 `q4` | 各问程序 |
| `03_src/fmodel/` | 公用函数：质量评分、标度律、成本、配比 |
| `03_src/run_all.py` | 全流程入口，论文附录中的程序与本目录逐字一致 |
| `03_src/paper_*.py`、`reporting_figures.py` | 论文用图与流程图 |
| `03_src/tools/` | 论文文档生成与打包脚本，不参与计算 |
| `tests/` | 单元测试 |
| `configs/datasets.json` | 附件编号与文件路径登记 |
| `02_data/processed/` | 处理后数据：逐样本质量分、C1 与 C4 匹配模型、C8 逐任务聚合 |
| `05_results/tables/` | 各问结果（JSON），与论文附录 1 的程序与结果文件对照表一致 |
| `05_results/models/` | 标度律参数、质量项参数、配比模型与参考配比 |
| `05_results/text_check/` | 冲突样本原文核验记录 |
| `08_logs/full_pipeline.log` | 生成随附结果时的运行日志 |

程序文件开头注释与论文附录中的 `04_代码/`，以及论文附录 1 中的 `03_结果文件/`、`02_结果图/`，
分别对应本支撑材料中的 `程序/`、`程序/05_results/`、`图片/`。
