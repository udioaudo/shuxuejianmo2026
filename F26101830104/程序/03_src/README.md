# 首轮程序基础

当前版本实现：原始附件登记审计、22项质量信号全量探索性评分和域级聚合、预定义冲突标记、A1/A18内容相似度映射、17域线性/平方/两两交互对照及正式检验集逐域重采样、经典标度律与轨迹留出、B2来源专属修正的外部对照、半合成质量情景、三档预算的有界配置与外推情景及质量边界扫描、C8逐任务聚合及损坏文件结果块恢复、C3时序汇总、C6桥接诊断、C1/C4匹配与时间留出及机构重采样、同口径C1预训练模型的高分位回测、2027年条件前沿及联合重采样不稳定范围、六张科研图。

正式F题数据已接入并产生真实的阶段结果。尚未解决的核心识别问题：第一问的Q需要更严格语义核验，11个配比域没有可靠的直接质量映射；第二问真实Q收益与配比效应不可由现有跨来源数据共同识别；第三问质量项来自半合成实验，大预算碰到B1范围边界；第四问的Loss桥接仍弱，同口径2025短期前沿回测通过，但2027长期外推不具备校准覆盖保证。结果报告位于 `06_paper/F题四问阶段研究报告.md`。

`tests/test_foundations.py` 内全部数据为数学构造测试夹具，仅检验实现，不是赛题附件、半合成补充集或独立实验结果。

从主工作目录运行：

```powershell
& .\.venv\Scripts\python.exe .\03_src\run.py audit
& .\.venv\Scripts\python.exe .\03_src\run.py formula-check
& .\.venv\Scripts\python.exe -m unittest discover -s tests -v
& .\.venv\Scripts\python.exe .\03_src\run_all.py
```

`configs/datasets.json` 的40个编号已依据数据说明和源文件清单逐项登记。路径相对 `02_data/raw`；目录型C8单独登记。文件存在不等于语义验证完成。

Q1评分的方向、A1百分位界与权重规则写入输出JSON，逐条记录保留；其文本有效性需复核。A18内容映射对已知6组找对5组，只列候选，不自动把11域质量当作真实观测。配比超参数只在训练集选择，首选平方项模型与参考p保存为joblib供Q2/Q3读取。Q2质量校准仅用半合成B6；B7与B6的360条重叠记录不充当独立检验；B2校准在B4上反而恶化。广义条件公式中的配比系数留为情景参数，不冒充已识别的效应。Q3并列保存B1观测范围内方案和向B9元数据范围放宽的外推情景；后者不是实测最优。Q4旧前沿模型未过回测，新的同口径模型通过2025短期回测，2027情景需连同宽的不稳定范围使用。
